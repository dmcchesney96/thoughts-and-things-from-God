## 2026-09-29 — Initial design preferences

**Task:** Define how thoughts in the "Thoughts and Things from God" project should be captured.

**User preference:** Keep the system simple. The user does not want complicated knowledge-management work or excessive process.

**User preference:** Preserve the user's voice. Clean up what was verbally dictated so it is clearer, but do not rewrite it into polished AI, academic, or devotional prose.

**User preference:** Preserve stories the user tells rather than stripping them away to get to a principle.

**User preference:** When the user vaguely references Scripture or another source, identify and include the reference when it can be resolved confidently.

**User preference:** The main experience should feel like the user simply talking into the project while the agent handles cleanup and filing.

**Promoted:** 2026-09-29 — encoded in `SKILL.md` and `AGENTS.md`.
