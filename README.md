# Thoughts and Things from God

A small agent/skill repository for faithfully capturing, clarifying, preserving, connecting, and retrieving spiritual thoughts.

## The simple idea

**You talk. The agent preserves.**

This repository is intentionally small. It does not contain the actual thought library. The canonical archive is the Google Drive folder named **Thoughts and Things from God**.

GitHub holds the instructions for how an AI assistant should care for that archive:

- keep the user's voice;
- preserve stories and lived context;
- clean up spoken/verbal clutter without flattening the thought;
- identify Scripture or source references when they are mentioned vaguely and can be resolved confidently;
- preserve uncertainty instead of turning exploration into conclusions;
- connect to earlier thoughts only when the connection is genuinely useful;
- save the finished note to the Google Drive archive with a clear, searchable title.

## Governing principle

> Faithful preservation is more important than polished writing.

The goal is not to produce the best theological essay possible from a raw thought. The goal is to produce the clearest faithful version of the thought the user actually had.

## Canonical archive

**Google Drive → Thoughts and Things from God**

The Drive library contains the thoughts. This repository contains the operating instructions.
